# M1 renderer corpus

The corpus is generated by the public testkit. Its original eight resources
are independently authored synthetic MIT art; the two additional immutable UI
resources retain their exact asset-manifest licenses. It has nine stable
scenarios. Four synthetic ones cover painter and cross-depth
overlap, fractional clipping, nearest/linear textured quads, clocked effects,
tall/multipart structural surfaces, translucent lighting/fog/cutaways,
geometric Interface-layer fixtures at 1.5x scale, unaligned GPU readback rows, and a
1,024-quad density case. Two world
scenarios run the world compiler on procedural art: an isometric hill with
stretched terrain, double-drawn tall art, a pulsing glow, tint, greyscale,
alpha, rotation and scale; and a top-down field with ground-first ordering, an
animated object and a glow. An atlas scenario draws everything from frames
of one procedural sprite-sheet atlas: abutting ground tiles, layered
characters (body, tunic and hair parts of one object) at each walk step and
at a fractional 1.5× scale, linearly filtered magnified frames whose edges must
not blend with neighbouring frames, a rotated frame, a frame whose
coordinates run past its edges, and a glowing frame above an opaque row. No
quad edge or texel boundary in it falls on a pixel centre, linear filter
fractions are eighths (exact in GPUs' 8-bit filter weights), and no pixel
blends more than one translucent layer, so every backend stays within the
shared tolerance. The manifest's `resources` list records each fixture
texture's identity, digest and provenance. The fixed
clock removes animation nondeterminism. Missing, digest-mismatched, corrupt, and
oversized resource cases, and a frame outside its texture, have exact expected
error classes.

RGBA comparisons permit at most one 8-bit channel of backend rounding variance.
Semantic ID, depth, and coverage planes are exact. No masks hide a pixel: each
semantic plane is itself the full comparison mask. Changes to a digest or
tolerance require visual, semantic, performance, and provenance review.
Each scenario also records deterministic work counts and a deliberately broad
CPU ceiling; the corpus runner fails when that ceiling is exceeded.

The two shared UI cases compile `UiPrimitive` solids and text through
`tilewright-render-ui::compile_ui` and `builtin_font`; glyphs are never manually
constructed test quads. A 320 × 192 logical display list targets 400 × 240
(DPI 1.25) and 480 × 288 (DPI 1.5). It shows a toolbar/button, palette swatches,
inspector label and common-Latin name, selected field, caret, numeric value,
visible unsupported-character fallback, and a scrolled text row whose original
atlas UVs are cropped through glyph ink at fractional clip edges. The font is
a reversible candidate; these fixtures do not imply owner approval of a font
or typography scope.

World semantic ID 9000 fills the target behind opaque UI panels. IDs 9100–9108
are explicit pickable panel/control blockers, and text IDs 9200–9208 are
nonpickable. Full reference semantic, depth and coverage planes are checked
against panel rectangles at both DPIs, including blank inspector space. The
scene checks UI/world identity and resource collisions and unique semantic/part
pairs. Nonpickable text leaves the panel blocker intact. An opaque nonpickable
panel would leave world IDs intact; application UI-first input routing remains
a separate consumer requirement.

The resource records for IDs 301 (Roboto Mono atlas, OFL-1.1) and 302 (synthetic
white solid, MIT) must exactly match `tilewright-render-ui/assets/manifest.json`
for digest, source, author, license, transformation and notice. The provenance
gate validates the pinned font assets and preserves the original eight strict
MIT/source/author checks. There is no general OFL fixture exception.

`tools/validate.sh` regenerates all nine deterministic manifests with the public
example, then runs all nine through the existing wgpu CLI corpus loop. That
loop compares every semantic/depth/coverage value exactly and every RGBA
channel within the existing tolerance of one. GPU evidence must record the
actual adapter/backend/driver from `tilewright-render probe`; software Vulkan
coverage is not hardware or native interactive UI acceptance.

The current wgpu implementation computes the returned semantic, depth and
coverage planes with shared CPU coverage. Exact returned-plane comparison
verifies that public contract; it does not establish GPU-rasterized picking.
RGBA comparisons exercise actual GPU rasterization and remain independently
required.
