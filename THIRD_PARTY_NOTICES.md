# Third-party notices

Rust dependencies retain their licenses as reported by Cargo metadata and the
release SBOM. `policy/dependencies.json` records the approved SPDX licenses and
exceptions, registry sources, and direct-dependency purposes; `Cargo.lock` fixes
the exact resolved versions and checksums.

The raw SDL window handle adapter in `tilewright-render-sdl3` is an independently
adapted form of the public `sdl3` 0.18.4
`examples/raw-window-handle-with-wgpu/main.rs` technique. The upstream crate and
example are MIT licensed. The destination narrows it to a private synchronous
bridge, adds explicit safety invariants, and exposes no wgpu handle.

## Unicode text layout

`tilewright-render-ui` shapes, lays out and rasterizes Unicode text with the
unmodified crates.io packages `parley`, `fontique`, `parley_engine`,
`parley_data`, `parley_emoji`, `parlance`, `harfrust`, `skrifa`, `read-fonts`,
`font-types`, `swash` and `zeno` (`MIT`, or `Apache-2.0 OR MIT`). `fontique` is
built without its `system` feature, so no platform font enumeration code is
linked. Line breaking, word segmentation and character properties come from
the ICU4X crates (`icu_segmenter`, `icu_properties`, `icu_normalizer`,
`icu_collections`, `icu_locale_core`, `icu_provider` and their compiled `*_data`
crates, with `zerovec`, `zerotrie`, `zerofrom`, `yoke`, `litemap`, `tinystr`,
`writeable` and `potential_utf`). Those crates and the Unicode data compiled
into renderer binaries and the browser bundles are distributed under the

## Browser package

The WebAssembly bundles in `packages/tilewright-render/wasm/` are built from
this workspace and link these Rust crates, beside the Rust dependencies
above, under `MIT OR Apache-2.0`:

- `wasm-bindgen`, `wasm-bindgen-futures`, `js-sys` and `web-sys`;
- `wgpu`'s browser backends.

They also link the Unicode text layout crates and ICU4X data described in
[Unicode text layout](#unicode-text-layout), under the licenses given there.

The JavaScript glue beside each bundle (`tilewright_render_web.js` and its
`.d.ts`) is generated by the `wasm-bindgen` command-line tool 0.2.127
(`MIT OR Apache-2.0`), pinned by version and SHA-256 in
`policy/toolchain.json`. The bundles are build output and are not committed.

The package's development dependencies are pinned by `package-lock.json`.
They are used to build and test it and are not distributed with it:

- `typescript` 6.0.3 (`Apache-2.0`);
- `playwright-core` 1.64.1 (`Apache-2.0`).

Browser tests drive an installed Google Chrome and download no browser.

## Roboto Mono UI font

`crates/tilewright-render-ui/assets/RobotoMono-Regular.ttf`, `atlas.atx`,
`metrics.json`, `glyphs.rs` and `source-cmap.json` contain Roboto Mono font data
or derived bitmap/metric data, distributed under **SIL Open Font License 1.1
(`OFL-1.1`)**. They are distinct from the MIT renderer implementation.

Copyright 2015 The Roboto Mono Project Authors
(https://github.com/googlefonts/robotomono).

The complete upstream copyright and license are retained in
`crates/tilewright-render-ui/assets/OFL.txt`. No Reserved Font Names are
declared in that notice. The unmodified Regular font is pinned to
[`googlefonts/RobotoMono` revision `895ec691990d041dd727c7b5afa3ce56525d98e6`](https://github.com/googlefonts/RobotoMono/blob/895ec691990d041dd727c7b5afa3ce56525d98e6/fonts/ttf/RobotoMono-Regular.ttf).
The 20 px bitmap conversion selects common-Latin scalars and a visible U+FFFD
fallback; it does not change or relicense the source font. Preserve `OFL.txt`
with these assets in source and binary distributions. `PROVENANCE.md`, the
asset manifest and `tools/ui-font/README.md` record the exact transformation.
